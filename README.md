# SkillKit - Бот довідник софту

Короче, це телеграм бот, який допомагає знайти купу крутих програм (софту) для різних професій (дизайнери, програмісти і тд). 

Він написаний на пайтоні і використовує aiogram і базу даних sqlite (sqlalchemy).

## Що він вміє:
* Показує красиві кнопочки з напрямками (типу Дизайн, Розробка).
* Коли тикаєш на напрямок - показує професії.
* Тикаєш на професію - бот видає список прог з описом, фішками і лінками на сайт чи відоси з ютуба.
* **Для користувачів:** можна запропонувати свій софт, професію чи напрямок через команду `/suggest`.
* **Для адміна:** є секретна адмінка `/admin`. Там можна додавати/видаляти категорії і софт. А ще там з'являються заявки від людей, їх можна схвалити (вони самі додадуться в базу) або відхилити.

## Як запустити цю штуку:

1. Спочатку робимо файл `.env` прямо в папці з ботом.
2. Пишемо туди:
   ```env
   BOT_TOKEN=СЮДИ_ВСТАВЛЯТИ_ТОКЕН_З_BOTFATHER
   ADMIN_ID=СЮДИ_ТВІЙ_ТЕЛЕГРАМ_ID (щоб адмінка працювала)
   ```
3. Скачуємо бібліотеки в консолі:
   ```bash
   pip install -r requirements.txt
   ```
4. Створюємо базу даних (запустити один раз):
   ```bash
   python create_models.py
   ```
5. Запускаємо самого бота:
   ```bash
   python main.py
   ```

Все! Бот працює, можна користуватися і захищати роботу.
